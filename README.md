# Mre_miniz_tools
App demonstrate how to zip/unzip files. Zip file size limited by phone memory.
For using with Nokia mobile phone, app must be signed with IMSI (your SIM card) code.
https://vxpatch.luxferre.top/
Application files - 
"[miniz_zip.vxp](https://rdzdx.github.io/mre_miniz_tools/miniz_zip.vxp)", 
"[mre_miniz_zip.vxp](https://rdzdx.github.io/mre_miniz_tools/mre_miniz_zip.vxp)", 
"[miniz_unzip.vxp](https://rdzdx.github.io/mre_miniz_tools/miniz_unzip.vxp)", 
"[miniz_ungz.vxp](https://rdzdx.github.io/mre_miniz_tools/miniz_ungz.vxp)".
mre_miniz_zip.vxp and miniz_ungz.vxp - works with blocks of files (not limited by phone memory).
